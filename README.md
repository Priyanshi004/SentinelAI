
# SentinelAI

AI-Powered Intelligent Cybersecurity Threat Detection and Network Monitoring System.

## Overview

SentinelAI is a machine-learning-based cybersecurity project designed to analyze network traffic, identify suspicious patterns, classify potential attacks, and monitor security alerts.

## Planned Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- FastAPI
- PostgreSQL
- Next.js
- React
- TypeScript
- Tailwind CSS

## Project Modules

1. Dataset Collection and Preparation
2. Machine Learning Threat Detection
3. Backend API Development
4. Security Monitoring Dashboard
5. Integration and Testing
6. Deployment

## Dataset

Initial model development will use the CIC-IDS2017 intrusion detection dataset.

Dataset source:
https://www.unb.ca/cic/datasets/ids-2017.html

Currently under development.
